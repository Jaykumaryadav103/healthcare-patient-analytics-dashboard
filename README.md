# 🏥 Healthcare Patient Analytics Dashboard

## 📌 Project Overview

This project focuses on analyzing healthcare and hospital data to generate meaningful business insights using **Excel, SQL, and Python**.

The analysis covers patient admissions, hospital departments, treatment costs, length of stay, revenue, insurance, payment methods, and patient satisfaction.

The main objective is to transform raw healthcare data into clear **reports, KPIs, visualizations, and actionable insights** that can support hospital management and operational decision-making.

---

## 🎯 Project Objectives

* Analyze patient admission trends
* Identify department-wise patient volume
* Analyze treatment and hospital costs
* Study patient length of stay
* Analyze hospital revenue
* Understand insurance and payment patterns
* Measure patient satisfaction
* Create management-ready reports and dashboards
* Practice real-world Data Analyst skills

## 📊 Dataset

The dataset contains synthetic healthcare patient records created for learning and portfolio purposes.

### Key Fields

| Column               | Description                |
| -------------------- | -------------------------- |
| Patient_ID           | Unique patient identifier  |
| Patient_Name         | Patient name               |
| Age                  | Patient age                |
| Gender               | Patient gender             |
| Department           | Hospital department        |
| Admission_Date       | Patient admission date     |
| Discharge_Date       | Patient discharge date     |
| Treatment_Cost       | Cost of treatment          |
| Length_of_Stay       | Number of days in hospital |
| Insurance            | Insurance provider         |
| Payment_Method       | Payment method             |
| Patient_Satisfaction | Patient satisfaction score |
| Doctor               | Assigned doctor            |
| Revenue              | Revenue generated          |
